# Privacy Policy for Flowstop

**Last Updated:** June 18, 2026

Flowstop ("the Extension") is a browser extension designed to provide true offline mode for specific browser tabs using Chrome's native DevTools Protocol.

We take your privacy seriously. The core principle of Flowstop is that it operates entirely locally on your machine.

## Information We Do Not Collect

Flowstop **does not** collect, store, transmit, or share any of the following information:
- Personal Identifiable Information (PII)
- Authentication information or credentials
- Web browsing history
- Location data
- User activity (clicks, mouse movements, keystrokes)
- IP addresses

## Data Used Locally

To function correctly, the Extension temporarily accesses the following data **locally on your device only**:
- **Tab URLs and Titles:** The Extension reads the title, URL, and favicon of the tabs you explicitly choose to isolate. This is required solely to display the list of currently offline tabs within the Extension's popup interface.
- **Session Storage:** The Extension stores the IDs of isolated tabs in your browser's local session storage so it remembers which tabs are offline while the browser is running. 

None of this data ever leaves your device. It is never transmitted to any external server, analytics service, or third party.

## Third-Party Services

Flowstop makes zero external network requests and contains no analytics, tracking code, or remote scripts. It does not integrate with any third-party services.

## Contact Us

If you have any questions or concerns about this Privacy Policy or the practices of this Extension, please contact the developer via the support link provided on the Chrome Web Store listing.
